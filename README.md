## 🎨 О проекте
Meowrch Code Theme - это динамическая тема для Visual Studio Code, которая синхронизирует стили [Meowrch](https://github.com/meowrch/meowrch) с интерфейсом редактора и позволяет мгновенно применять изменения через внешний конфигурационный файл.

## ⚡ Быстрый старт
Установите расширение через [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=dimflix-official.meowrch-theme)


## 🔄 Динамическое изменение темы
### Как это работает:
- Расширение отслеживает изменения в `~/.config/meowrch-code-theme/theme.json`
- При любом изменении файла тема автоматически обновляется
- VS Code перезагружает интерфейс для применения изменений

## 🛠 Устранение неполадок

Если тема не применяется:
1. Проверьте правильность JSON-формата
2. Убедитесь, что имя темы совпадает с установленной в VS Code
3. Проверьте логи расширения: `View → Output → Meowrch Theme`
